Build with Slate.

Define C and C++ targets in JSON. Slate resolves your toolchain, generates Ninja rules, and lets you build, run, test, and install from one CLI.

Quickstart Download Slate

Run your first build

Install the CLI

Get the release archive for your host. Keep the extracted bundle together and add its bin/ directory to PATH. You also need Ninja 1.10 or later and a C/C++ toolchain.

slate --version
ninja --version

Build the sample

From the source checkout, use apps/ as the project root. On Windows, see toolchain setup for the LLVM-MinGW and MSVC presets.

git clone https://github.com/qigao/slates-build.git
cd slates-build
slate doctor --root apps --target hello
slate run --root apps --target hello

Use Slate in your project

Configure targets

Define presets in slate.json and targets in module.json. Look up accepted fields in the manifest reference.

Test and install

Run registered tests with slate test and stage build artifacts with slate install.

Work in VS Code

Use the Slate extension to select presets, browse targets, and launch builds and tests.
